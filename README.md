# Control Center

Centre de contrôle en verre dépoli (Liquid Glass) pour Android, ouvert par un swipe vers le bas
depuis le coin supérieur droit de l'écran.

## Installation
1. Onglet **Releases** du dépôt → télécharger `ControlCenter.apk` → installer.
2. Ouvrir l'app et suivre les 4 étapes (accessibilité obligatoire, le reste est optionnel).
3. Sur Samsung : Infos de l'app → ⋮ → « Autoriser les paramètres restreints » avant d'activer l'accessibilité.

## Ce qui fonctionne
- Lampe, luminosité, volume, Ne pas déranger, rotation auto, capture d'écran, verrouillage
- Lecteur média (titre, pochette, play/pause/suivant/précédent)
- Raccourcis : appareil photo, calculatrice, minuteur, réglages
- Wi-Fi / Bluetooth / données / mode avion : état affiché, un appui ouvre le panneau système
  (Android interdit à une app classique de les basculer directement)
